Protocol — CLI Ledger

The standalone portable Go core plus checks. Shares bytes by CID; the Go binary is the product runtime. Needs a built Ledger binary and a folder of files.

Parcel

Desktop file-sharing app using Ledger. Scans a folder, serves it, joins peers from invites or ledger:// links, and fetches verified bytes. Ships as Parcel.app.
