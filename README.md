# lplvlql.github.io

Project hub for lplvlql. The root page is only an index — each project has its own site:

- `chronicle/` — Chronicle (tabletop card-game workspace)
- `ledger/` — Ledger (protocol, Parcel, Wizard Poker, Parcel Pocket)
- `usual-time/` — Usual Time (Daisy Terrarium delay / looper)
- `mister-simp/` — mister-simp (MiSTer SD-card layout tool)

Plain static files, relative links, no build step. Runs on GitHub Pages today; the same files can be served from Ledger hosting later without changes.

Preview locally:

```sh
python3 -m http.server 8000
# open http://localhost:8000
```
