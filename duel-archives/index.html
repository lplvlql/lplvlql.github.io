A project to decompile and improve the five Yu-Gi-Oh! GBA simulators released between 2002 and 2006 — one game for each year, with better AI, more interesting decks, and fixes to the original games, while keeping each year's card pool and mechanics intact.

2002 — The Eternal Duelist Soul

  • Builds on an existing decompilation.

2003 — Worldwide Edition: Stairway to the Destined Duel

  • Currently being decompiled.

2004 — World Championship Tournament 2004

  • Planned.

2005 — 7 Trials to Glory: World Championship Tournament 2005

  • Planned.

2006 — Ultimate Masters: World Championship Tournament 2006

  • Planned.

Approach

Each year's game stays itself: same card pool, same mechanics. The work is under the hood — an AI that puts up a fight, decks worth dueling against, and the original bugs fixed.
