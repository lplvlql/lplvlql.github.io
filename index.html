Ledger

Minimal content-addressed give/take. Live peers use HTTP today; CIDs and local state stay transport-neutral.

Go · CID addressing · HTTP today · 4 repos, one-way deps

The four parts

  • Protocol (CLI Ledger) — standalone Go core. Shares bytes by CID. GitHub →
  • Parcel — desktop file sharing on Ledger. Scans a folder, serves it, joins via invites or ledger:// links.
  • Wizard Poker — one-table Flash Poker vs three local bots. Boots straight to the felt; knock to commit.
  • Parcel Pocket — future phone companion. Planned, not built yet.

This hub is plain static files — the plan is to serve it from Ledger itself later, no rebuild needed.

mister-simp

One script that migrates a standard MiSTer SD-card layout into a simplified one — and keeps the helper scripts current on later runs.

Shell · targets /media/fat · github.com/lplvlql/mister-simp

What it does

  • Keeps required root files/folders; removes everything off the allowlists.
  • Normalizes folder names to the canonical layout.
  • Installs helpers into scripts/: clean, update, cache, random, last, delete.

Run mister-simp.sh from scripts/ on the MiSTer. No argument = /media/fat; pass a path to target something else.
